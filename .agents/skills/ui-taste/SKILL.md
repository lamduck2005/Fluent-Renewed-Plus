# UI Taste

## Workflow

1. Consult component sources in `Src/Components/` and `Src/Elements/` before altering or adding new elements.
2. Read `references/anti-slop.md` before finalizing visual elements - avoid decorative AI-visual artifacts and unnecessary clutter.
3. Read `references/design-guidelines.md` for spacing, typography hierarchy, states, and animation timing.
